# No chapters found

Chapters come from scanlation sources, not from PlayzAnime, and no single source has everything. When a series shows no chapters, or stops early, it's almost always on another source.

## 1. Try another source

On the series page, open **Source** above the chapter list. It lists every source PlayzAnime checked for this title, with how many chapters each has. Pick one with more. Your choice is remembered for that series. See [Read from another source](/docs/reading/read-from-another-source).

## 2. Turn on more sources

**Settings**, **Sources** has the built-in sources and around 55 community sources, each with its own switch. Sources you've turned off aren't searched. Turn on any that cover the kind of series you read (manhwa, manga, manhua or webtoons), then open the series again.

## 3. Check the sources are up

The **Built-in sources** list in **Settings**, **Sources** shows which answer right now and how fast. Click **Check again** to refresh it. **Auto** already skips sources that are down.

## Why a title might not be found

- **It's new.** Sources can take days to add a series AniList already lists.
- **It has another name.** PlayzAnime searches using the English and romaji titles and the other names AniList knows. A source that uses a very different title can be missed.
- **It's licensed.** Some sources remove series when an official English release starts.
- **It's on the web app.** A few sources block cloud servers, which the web app uses. The Windows app connects from your own PC and reaches every source.

## Still stuck?

Open an issue on [GitHub](https://github.com/PlayzAe/playz_anime_desktopapp/issues) with the series name and which sources you tried.
