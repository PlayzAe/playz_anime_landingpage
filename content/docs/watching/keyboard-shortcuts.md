# Keyboard shortcuts

Shortcuts don't fire while you're typing in a text box. A short list is also in **Settings**, **Keyboard**.

## Anywhere

| Keys | Action |
|---|---|
| `Ctrl K` or `/` | Search anime and manga |
| `Alt ←` / `Alt →` | Back and forward |
| Mouse back / forward buttons | Back and forward |
| `F11` | Full-screen window |
| `F5` or `Ctrl R` | Reload the page, fetching everything again, images included |

## Player

| Keys | Action |
|---|---|
| `Space` or `K` | Play / pause |
| `J` / `L` | Back / forward 10 seconds |
| `←` / `→` | Back / forward 5 seconds |
| `↑` / `↓` | Volume up / down |
| `M` | Mute / unmute |
| `0` to `9` | Jump to 0% to 90% of the episode |
| `S` | Skip intro (while the intro plays) |
| `N` / `P` | Next / previous episode |
| `C` | Cycle subtitles, then off |
| `F` | Full screen |
| `T` | Theater mode |

Mouse: click the video to play or pause, double-click for full screen.

Pressing `←`, `→`, `J` or `L` several times in quick succession, or holding one down, adds the jumps together (+5 s, +10 s, +15 s) and seeks once.

## Reader

| Keys | Action |
|---|---|
| `[` / `]` | Previous / next chapter |
| `M` | Switch between scroll and page mode |
| `F` | Full screen |
| `Esc` | Leave the reader |
| `←` / `→` (page mode) | Turn the page. With right-to-left reading, `←` goes forward. |
| `Space` or `Page Down` (page mode) | Next page |
| `Page Up` (page mode) | Previous page |

## Search

| Keys | Action |
|---|---|
| `↑` / `↓` | Move through results |
| `Enter` | Open |
| `Ctrl Enter` | See all results in Discover |
| `Esc` | Close |
