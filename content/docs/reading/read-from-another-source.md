# Read from another source

Sources go down, and sometimes a source loses a single chapter. The same chapter number on another source is just as good, so PlayzAnime can switch for you.

## When a chapter won't load

If a chapter's pages can't be fetched, the reader shows **Couldn't load this chapter** with two buttons:

- **Try again** asks the same source again.
- **Read this chapter from another source** looks for the same chapter number on the other sources.

When it finds one, it opens it there and tells you, for example **Reading chapter 57 from WeebCentral**. If no other source has it, you'll see **No other source has this chapter right now.**

> [!NOTE]
> The button only appears for numbered chapters. Oneshots have no number to match.

## When a chapter is empty

If a source returns a chapter with no pages, the reader says **This chapter has no pages**. Go back to the manga page and pick another source from the **Source** switch above the chapter list.

## Switch the whole series

To read an entire series from a different source, open its manga page and choose one from the **Source** switch. Each option shows how far that source goes, for example `Flame Comics · ch. 88`.

To prefer one source for every title, use **Settings**, **Reading**, **Manga source**. See [Sources and auto-pick](/docs/reading/sources-and-auto-pick).

## Your progress when you switch

Read chapters are tracked by chapter number, so chapter 57 read on one source is still marked read when you look at the list from another source.
