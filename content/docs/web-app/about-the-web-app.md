# PlayzAnime on the web

The web edition of PlayzAnime runs directly in modern browsers on desktop, tablet, and mobile. It provides the same sleek catalog, custom video player, and manga reader as the desktop client without installing any software.

- **Official Web App URL:** [playz-anime.onrender.com](https://playz-anime.onrender.com)
- **Status:** 24/7 Cloud Hosted (Render)

---

## Features on the web

- **Native HLS Video Player:** Powered by `hls.js` with adaptive bitrate (1080p, 720p, 480p), keyboard shortcuts, picture-in-picture, and subtitle support.
- **Auto Skip Intro & Outro:** Automatically detects episode intro/outro marks and skips them seamlessly.
- **Dual-Audio:** Instant switching between Sub (Japanese with subtitles) and Dub (English).
- **Manga & Manhwa Reader:** Multi-source reader with MangaDex, WeebCentral, Flame Comics, and MangaPill. Supports vertical webtoon scrolling and traditional right-to-left paging.
- **Direct AniList Engine:** Instant search, trending releases, seasonal charts, and airing schedule queried directly in your browser.
- **Zero Tracking:** Your watchlist, reading progress, and custom settings stay 100% private in browser local storage.

## Differences from the Windows App

| Feature | Windows Desktop App | Web App (Render) |
|---|---|---|
| Streaming Anime | Yes | Yes |
| Reading Manga | Yes | Yes |
| AniList Catalog & Search | Yes | Yes |
| Private Watch History | Local File (`%APPDATA%`) | Browser Storage (`localStorage`) |
| Offline Downloads (MP4/CBZ) | Yes | No (Desktop only) |
| System Tray & Windows Media Keys | Yes | No |
| Discord Rich Presence | Yes | No |
