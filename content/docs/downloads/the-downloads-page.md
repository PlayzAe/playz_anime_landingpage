# The Downloads page

Open **Downloads** from the left rail. The icon shows a number while downloads are running.

![Downloads, grouped by series and quality](/screenshots/downloads.webp)

## Folders

The top of the page shows where episodes and chapters are saved, each with **Open** and **Change**. See [Folders and file names](/docs/downloads/folders-and-naming).

## In progress

Everything queued or downloading, with a progress bar and a status line such as:

```
42% · 3.1 MB/s · about 2 min left · 180 MB so far
```

**Cancel** stops a download and throws away what it had saved.

## Needs attention

Downloads that failed or were cancelled. Each one says what went wrong and how much was saved, and has:

- **Resume**, when part of it was saved, or **Retry**, when nothing was.
- **Remove from list** in the **⋯** menu.

The messages are explained in [Resume and errors](/docs/downloads/resume-and-errors).

## On this device

Finished downloads, grouped the way you'd look for them:

1. **Series**, newest first, with the number of episodes or chapters and the total size. **Play** or **Read** starts at the first one.
2. **Episode or chapter** within the series.
3. **Copies** of the same episode, for example `1080p SUB` and `720p DUB`, each with its size.

Click a copy to play or read it inside PlayzAnime. The **⋯** menu on each copy has:

| Option | What it does |
|---|---|
| **Open in another player** / **Open in another reader** | Opens the file in your default app for MP4 or CBZ |
| **Show in folder** | Opens File Explorer with the file selected |
| **Remove from PlayzAnime (keep file)** | Takes it off this page. The file stays on disk. |
| **Delete the file** | Removes it from this page and deletes the file |

## Missing files

If you move, rename or delete a downloaded file outside PlayzAnime, its copy is marked **Missing**. Clicking it explains what happened instead of failing to play. Remove it from the page, or download it again.

> [!TIP]
> To reorganise your files, change the download folder in PlayzAnime for new downloads, and leave existing files where they are. PlayzAnime remembers each file's full path.

> [!NOTE]
> PlayzAnime keeps records of your 300 most recent downloads. If you go past that, the oldest drop off this page after a restart. Their files stay on disk and still open in other apps.
